=== Glossary Tooltips ===

Справочная система для технических терминов в статьях.

Клик по термину открывает всплывающее окно с:
- пояснением
- примерами использования
- рекомендациями, в каких случаях применять

== Установка ==

1. Активировать плагин в разделе «Плагины».
2. Добавить термины в меню «Глоссарий».
3. Заполнить пояснение, примеры и случаи использования.

== Добавление термина ==

- Заголовок — сам термин (например: API, REST, PHP).
- Пояснение — краткое объяснение для пользователя.
- Примеры — по одному на строку.
- В каких случаях — когда уместно применять.
- Алиасы — варианты написания через запятую (API, апи).

== Примечания ==

- Термины подсвечиваются только в записях (постах).
- Внутри блоков <code> и <pre> подсветка отключена.
