Введение

В этой статье я расскажу, как реализовать "умный" липкий сайдбар, который прилипает к хедеру при прокрутке страницы и возвращается на место при возврате наверх.

Что мы реализуем

  • При прокрутке — сайдбар прилипает к нижней части хедера с отступом 20px
  • При возврате наверх — сайдбар возвращается на своё место
  • Если сайдбар длинный — добавлена прокрутка внутри него с красивым тонким скроллбаром
  • Максимальная высота — ограничена, чтобы не выходить за пределы экрана

JavaScript код

Создаём файл sticky-header.js в папке с JS-файлами темы:

/**
 * Smart Sticky Header & Sidebar for DekanPro Theme
 * Хедер и сайдбар становятся фиксированными при прокрутке
 */

(function() {
    'use strict';

    function initStickyElements() {
        const header = document.getElementById('masthead') || document.querySelector('.site-header');
        const dekanproHeader = document.getElementById('dekanpro-header');
        const sidebar = document.getElementById('secondary') || document.querySelector('.dekanpro-sidebar-container');
        
        if (!header) return;

        // Создаём плейсхолдер для компенсации высоты хедера
        const placeholder = document.createElement('div');
        placeholder.className = 'header-placeholder';
        header.parentNode.insertBefore(placeholder, header.nextSibling);

        let headerHeight = header.offsetHeight;
        let dekanproHeaderHeight = dekanproHeader ? dekanproHeader.offsetHeight : headerHeight;
        let isHeaderSticky = false;

        // Обновляем высоту при ресайзе
        window.addEventListener('resize', function() {
            if (!isHeaderSticky) {
                headerHeight = header.offsetHeight;
                dekanproHeaderHeight = dekanproHeader ? dekanproHeader.offsetHeight : headerHeight;
            }
            // Обновляем top для сайдбара
            if (sidebar && sidebar.classList.contains('is-sticky')) {
                sidebar.style.top = dekanproHeaderHeight + 20 + 'px';
            }
        });

        // Обработчик скролла
        function handleScroll() {
            const scrollTop = window.pageYOffset || document.documentElement.scrollTop;

            // Sticky Header
            if (scrollTop > headerHeight && !isHeaderSticky) {
                isHeaderSticky = true;
                header.classList.add('is-sticky');
                placeholder.classList.add('is-active');
                placeholder.style.height = headerHeight + 'px';
            } else if (scrollTop <= headerHeight && isHeaderSticky) {
                isHeaderSticky = false;
                header.classList.remove('is-sticky');
                placeholder.classList.remove('is-active');
                placeholder.style.height = '0';
            }

            // Sticky Sidebar
            if (sidebar) {
                if (scrollTop > headerHeight) {
                    sidebar.classList.add('is-sticky');
                    sidebar.style.top = dekanproHeaderHeight + 20 + 'px';
                } else {
                    sidebar.classList.remove('is-sticky');
                    sidebar.style.top = '';
                }
            }
        }

        // Слушаем скролл с оптимизацией через requestAnimationFrame
        let ticking = false;
        window.addEventListener('scroll', function() {
            if (!ticking) {
                window.requestAnimationFrame(function() {
                    handleScroll();
                    ticking = false;
                });
                ticking = true;
            }
        }, { passive: true });

        // Проверяем начальное состояние
        handleScroll();
    }

    // Запускаем после загрузки DOM
    if (document.readyState === 'loading') {
        document.addEventListener('DOMContentLoaded', initStickyElements);
    } else {
        initStickyElements();
    }
})();

CSS стили

Добавляем стили в файл custom-modern.css или в кастомный CSS темы:

/* Sticky Sidebar */
#secondary.is-sticky,
.dekanpro-sidebar-container.is-sticky {
    position: fixed !important;
    max-height: calc(100vh - 100px);
    overflow-y: auto;
    width: inherit;
    transition: top 0.3s ease !important;
}

/* Красивый тонкий скроллбар для сайдбара */
#secondary.is-sticky::-webkit-scrollbar {
    width: 4px;
}

#secondary.is-sticky::-webkit-scrollbar-track {
    background: transparent;
}

#secondary.is-sticky::-webkit-scrollbar-thumb {
    background: rgba(99, 102, 241, 0.3);
    border-radius: 4px;
}

#secondary.is-sticky::-webkit-scrollbar-thumb:hover {
    background: rgba(99, 102, 241, 0.5);
}

/* Sticky Header */
#masthead.is-sticky,
.site-header.is-sticky {
    position: fixed !important;
    top: 0 !important;
    left: 0 !important;
    right: 0 !important;
    width: 100% !important;
    box-shadow: 0 4px 20px rgba(0, 0, 0, 0.1) !important;
}

/* Плейсхолдер для компенсации высоты при фиксации */
.header-placeholder {
    display: none;
}

.header-placeholder.is-active {
    display: block;
}

Подключение скрипта в WordPress

В файле functions.php или в классе подключения скриптов добавляем:

// Enqueue Smart Sticky Header & Sidebar
wp_enqueue_script(
    'dekanpro-sticky-header',
    get_template_directory_uri() . '/assets/js/sticky-header.js',
    array(),
    '1.0.0',
    true
);

Как это работает

1. Инициализация

Скрипт находит хедер и сайдбар по их ID или классам. Создаётся плейсхолдер — пустой div, который будет занимать место хедера когда тот станет фиксированным.

2. Обработка скролла

При каждом скролле проверяется позиция страницы:

  • Если прокрутили больше высоты хедера — добавляем класс is-sticky
  • Если вернулись наверх — убираем класс

3. Оптимизация производительности

Используется requestAnimationFrame для оптимизации — обработчик скролла вызывается не чаще 60 раз в секунду, что предотвращает "тормоза" при прокрутке.

4. Адаптивность

При изменении размера окна (resize) пересчитывается высота хедера и позиция сайдбара.

Особенности реализации

Плейсхолдер

Когда хедер становится position: fixed, он "выпадает" из потока документа и контент "прыгает" вверх. Плейсхолдер занимает освободившееся место и предотвращает этот скачок.

Прокрутка внутри сайдбара

Если сайдбар длиннее экрана, добавляется внутренняя прокрутка с max-height: calc(100vh - 100px). Скроллбар стилизован под общий дизайн сайта.

Плавные переходы

CSS-свойство transition: top 0.3s ease обеспечивает плавное появление sticky-эффекта.

Заключение

Такой подход к sticky-элементам обеспечивает:

  • Плавную работу без "дёрганий"
  • Высокую производительность благодаря оптимизации
  • Адаптивность под разные размеры экрана
  • Красивый внешний вид с кастомным скроллбаром

Код можно легко адаптировать под любую WordPress тему, изменив селекторы элементов.
